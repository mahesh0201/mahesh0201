> `Python` `IoT` `Sensor Integration` `Cloud`

Real-time hazardous gas detection system using wearable IoT sensors and microcontrollers. Transmits alerts to a monitoring dashboard, reducing direct worker exposure to toxic sewer environments.

### 👟 Smart Shoes — obstacle detection for the visually impaired
> `Arduino` `C++` `Ultrasonic Sensors` `Haptic Feedback`

Embedded hardware system integrated into footwear using ultrasonic distance sensors and vibration motors. Detects obstacles up to 2 meters and delivers haptic alerts for real-time navigation assistance.
